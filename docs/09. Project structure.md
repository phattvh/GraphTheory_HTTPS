# Cấu trúc thư mục dự án (Project Structure)

**Dự án:** Hệ thống xếp lịch thi tập trung bằng thuật toán tô màu đồ thị  
**Mục đích:** Quy ước thống nhất vị trí đặt mã nguồn, tài liệu và file kiểm thử cho cả 5 thành viên (TV1–TV5), giúp tổ chức file gọn gàng và hạn chế tối đa xung đột Git (*merge conflict*).

## 2. Quy ước tổ chức chi tiết theo từng khu vực

### 2.1. Thư mục `web/` (Frontend — TV4 & TV5)
- **Tách riêng 4 trang HTML cho 4 khu vực Admin** đặt thẳng ở gốc `web/` (cùng `login.html` và `student.html`):
  - `/index.html` (`/`): Quản lý dữ liệu (bảng CRUD, modal nổi Thêm/Sửa, modal Nạp & Xuất CSV/Excel và alert xác nhận Xóa — **TV5**).
  - `/graph.html`: Đồ thị xung đột & Xếp lịch tự động (**TV5** — chỉ nhúng `Cytoscape.js`).
  - `/calendar.html`: Lịch thi toàn trường (**TV4** — chỉ nhúng `FullCalendar`).
  - `/stats.html`: Thống kê & Phân tích đồ thị (**TV4** — chỉ nhúng `Chart.js`).
  - **Lý do tách:** tránh conflict Git giữa TV4 & TV5 khi sửa chung 1 file HTML lớn, mỗi trang chỉ nạp đúng thư viện CDN mình cần, và tránh lỗi tính sai kích thước (`width = 0`) của Cytoscape.js / FullCalendar khi nằm trong tab ẩn (`display: none`).
- **Tài nguyên thương hiệu dùng chung (`web/assets/logo.svg`):**
  - Toàn bộ 6 trang HTML dùng chung logo vector nền trong suốt `web/assets/logo.svg` cho header, sidebar, trang đăng nhập và favicon (`image/svg+xml`).
- **Dùng chung Sidebar & Top Header qua `web/js/admin/layout.js`:**
  - Hàm `initAdminShell(activePage)` tự render khung Header full-width (nút mở menu biểu tượng kiểu GitHub, logo `HTTPS`, thanh danh mục CRUD liền mạch nền trắng với mục đang chọn chữ xanh đậm + gạch dưới, nút Đăng xuất) và Sidebar trượt vào cả 4 trang Admin, tránh copy-paste HTML lặp lại.
- **Tách JS theo 3 nhóm:**
  - `web/js/core/`: hàm dùng chung (`api.js`, `auth.js`, `login.js`).
  - `web/js/admin/`: mỗi trang Admin gắn 1 file JS riêng (`layout.js`, `crud.js`, `graph.js`, `calendar.js`, `stats.js`).
  - `web/js/student/`: logic riêng cho Cổng Sinh viên (`portal.js`).
- **CSS:** ưu tiên dùng class **Tailwind CSS (CDN)** trực tiếp trong HTML; chỉ viết vào `web/css/layout.css` những quy tắc bổ trợ (như `.https-brand-wordmark`, `@media print`, kích thước khung `#cy` của Cytoscape).

### 2.2. Thư mục `backend/` (Backend — TV1, TV2, TV3)
- Tách rõ 4 lớp: `routers/` (tiếp nhận HTTP) $\rightarrow$ `algorithms/` (xử lý đồ thị & xếp lịch) $\rightarrow$ `models/` & `schemas/` (ORM & Pydantic) $\rightarrow$ `core/` (cấu hình, DB, bảo mật JWT).
- **Mỗi nhóm API 1 file router riêng** (`auth.py`, `master_data.py`, `import_export.py`, `schedule.py`); file `backend/main.py` chỉ đăng ký `app.include_router(...)`.

### 2.3. Thư mục `tests/` (Kiểm thử tự động)
- Đặt tên thống nhất theo mẫu `<ten_chuc_nang>_test.py`.
- Thư mục `tests/` được mount read-only vào container `fastapi` (`/app/tests:ro`), chạy test thống nhất bằng:
  ```bash
  docker compose exec fastapi python tests/<ten_chuc_nang>_test.py
  ```
